## 下载方式（无需登录）

GitHub 直链：

```
https://raw.githubusercontent.com/{{你的用户名}}/{{仓库名}}/main/template.pptx
```

Gitee 直链：

```
https://gitee.com/{{你的用户名}}/{{仓库名}}/raw/main/template.pptx
```

如果仓库默认分支是 `master` 而不是 `main`，请把链接里的 `main` 改成 `master`。

在任意联网设备上用浏览器打开上面的链接即可下载，不需要登录账号。也可以命令行下载：

```bash
curl -L -O https://raw.githubusercontent.com/{{你的用户名}}/{{仓库名}}/main/template.pptx
```

## 使用建议

- 用 PowerPoint 或 WPS 打开 `template.pptx`，替换示例文字、图片和配色。
- 如果模板中包含第三方字体、图标或图片，请自行确认这些素材是否允许再分发。
- 分发修改版时，请保留本仓库链接或署名信息。
